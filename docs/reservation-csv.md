# 取り置きの CSV の様式

管理画面の「取り置き」で取り込む CSV の様式です。管理画面の「⬇ 様式（記入例つき）」で、登録済みの券種名を使った記入例を保存できます（このリポジトリの [reservations-sample.csv](reservations-sample.csv) も同じ形です）。

## 書き方

1 行目が見出し、2 行目から 1 行に 1 件（または 1 件の 1 券種）を書きます。列の順番は自由です。

```csv
番号,氏名,フリガナ,券種,枚数,支払,金額,備考
1,岡大 太郎,オカダイ タロウ,一般,2,当日,,
2,グリー 花子,グリー ハナコ,一般,1,済,,振込済み
2,グリー 花子,グリー ハナコ,学生,1,済,,
3,合唱 次郎,ガッショウ ジロウ,招待,2,,,関係者
```

| 列 | 必須 | 内容 | 見出しの別の書き方 |
|---|---|---|---|
| 番号 | （おすすめ） | 取り置きの番号。数字でも `A-12` のような文字でもよい（20 文字まで）。**同じ番号の行は 1 件にまとめる**。取り込み直したとき、同じ番号の取り置きは同じものとして更新する。空欄なら今ある番号の続きの数字を自動で付ける | 受付番号・予約番号・整理番号・No |
| 氏名 | ○ | お客さんの名前（受付のカードに大きく出る・検索に使う） | 名前・お名前・予約者・代表者 |
| フリガナ | | 受付での検索と、名前順（五十音順）の並びに使う。ひらがなでもよい | ふりがな・カナ・よみ |
| 券種 | △ | 管理画面の「券種・価格」の券種名と**同じ名前**。券種が 1 つだけなら省いてよい | チケット・種類・席種 |
| 枚数 | | その券種の枚数。空欄なら 1 | 数・数量・人数 |
| 支払 | | `済`（事前に支払済み・受付では受け取らない）か `当日`（受付で受け取る）。**空欄は `当日`** | 支払状況・精算・入金 |
| 金額 | | 合計金額（円）。空欄なら券種の価格から計算する（セット価格も使う）。割引などで違うときだけ書く。`1,500` や `1500円` でもよい | 代金・料金 |
| 備考 | | 受付のカードに出す連絡事項（例：車いす、関係者） | メモ・連絡事項・コメント |

- **1 人が複数の券種を取り置いたとき**は、同じ番号で行を分けます（上の例の「2」）。氏名と支払は同じにしてください（違うとエラー）。
- 券種ごとの列で書くこともできます。見出しを券種名（例：`一般`、`学生(枚)`）にして、枚数を書きます。

  ```csv
  番号,氏名,一般,学生,支払
  1,岡大 太郎,2,,当日
  2,グリー 花子,1,1,済
  ```

- `支払` に書ける言葉：`済`・`済み`・`支払済`・`振込済`・`入金済`・`前払い`・`○`（支払済み）／`当日`・`当日精算`・`未`・`未払い`・空欄（当日）
- 文字コードは **UTF-8**（BOM あり・なし）でも **Shift_JIS**（Excel で「CSV（コンマ区切り）」で保存したもの）でもかまいません。管理画面が自動で見分けます。
- 1 公演 3,000 件まで。ファイルは 2MB まで。

## 取り込み方

ファイルを選ぶと、**取り込む前に**内容を確認できます（何も書き込みません）。

- 件数・枚数・受付で受け取る額の合計、1 件ずつの内容と「新規／更新／変更なし」
- 直すところ（行番号つき）。直すところが 1 つでもあると取り込めません
- 注意（使わない列がある、受け渡し済みの取り置きが消える、番号を自動で付ける など）

| 取り込み方 | CSV にある取り置き | CSV にない取り置き |
|---|---|---|
| 追加・更新 | 番号が同じなら内容を更新、なければ追加 | そのまま残す |
| この CSV に置き換える | 同上 | **削除する** |

どちらでも、**同じ番号の取り置きの受け渡しの記録（受け渡した時刻・渡した人）は残ります**。CSV にフリガナや備考の列がないときは、今の値を残します。本番の途中で取り置きを追加・修正するときも、番号を付けて取り込めば受付の画面に数秒で反映されます。

## 書き出し（取り置きの一覧と受け渡し）

管理画面の「⬇ 取り置きの一覧と受け渡し」（`reservations.csv`）は、取り込みの様式の列に受け渡しの状況を足したものです。そのまま取り込み直すこともできます（足した列は読み飛ばします）。

| 列 | 内容 |
|---|---|
| 番号・氏名・フリガナ | 取り込んだ内容 |
| （券種名）(枚) | 券種ごとの枚数（今の券種の並び順） |
| 枚数計 | 枚数の合計 |
| 支払 | `済` / `当日` |
| 金額(円) | チケット代の合計 |
| 受付で受け取る額(円) | 支払が `当日` なら金額、`済` なら 0 |
| 受け取った額(円) | 受け渡し済みなら「受付で受け取る額」、まだなら 0 |
| 受け渡し | `済` / `未` |
| 受け渡し日時 | ISO 8601（日本時間。例 `2027-06-01T13:05:12+09:00`） |
| 受け渡した人 | 受付でログインした名前 |
| 備考 | 取り込んだ内容 |

UTF-8（BOM 付き。Excel でも文字化けしない）、改行は CRLF です。
