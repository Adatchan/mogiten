# 定演チケットシステムのデザインシステム

定演チケットシステム（入口・受付・レジ・管理画面・会計の一覧）で共通に使う、見た目と操作のきまりです。
土台は [デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/) で、実装は [HTML 版のコードスニペット](https://github.com/digital-go-jp/design-system-example-components-html)（MIT License）に合わせています。

## 方針

| 項目 | DADS から | このシステムで決めたこと |
|---|---|---|
| 色 | トークンの持ち方（プリミティブ → 役割の 2 段） | 色そのものは **これまでの色（茶・ピンク・クリーム）を引き継ぐ** |
| フォント | Noto Sans JP | そのまま使う |
| 文字の大きさ | タイポグラフィの段階（12・14・16・18・20・24・32・45・57px…）、字間 0.02em | 業務画面は行間 1.5（Dense 寄り）、ヘルプの文章は 1.7 |
| フォーカス | 黒の枠 4px ＋ 黄色のふち | そのまま全画面・全部品に使う |
| ボタン | 塗り／アウトライン、高さの段階、カーソルで下線 | 標準 40px・small 32px・big 56px |
| 入力欄 | 濃い枠（背景と 3:1 以上）・角丸 8px | そのまま使う。枠の色は墨（`--mg-ink-600`） |
| 角丸 | 4・6・8・12・16px | タグ 4／小さいボタン 6／ボタン・入力欄・ダイアログ 8／カード 12／下から出るシート 16 |
| 影 | エレベーション | トースト・ダイアログは `--elevation-3`、画像は `--elevation-1` |
| ダイアログ | モーダルダイアログ（黒の枠・角丸 8px） | ヘルプのダイアログに使う |

## ファイル

| ファイル | 中身 | 書き換えてよいか |
|---|---|---|
| `public/tokens.css` | DADS のトークン（`--color-*`・`--font-family-*`・`--elevation-*`）をそのまま写したもの | **書き換えない**（DADS の更新を取り込むときだけ差し替える） |
| `public/app.css` | 1. このシステムのプリミティブカラー（`--mg-cream-*` など）<br>2. 役割のトークン（`--mg-*`）<br>3. 全画面で共通の部品（見出し・カード・ボタン・入力欄・タグ・ログイン・トースト） | ここで決める |
| `public/help.css` | ヘルプのボタンとダイアログ | 色・形は `--mg-*` を使う |
| 各画面の HTML の `<style>` | その画面だけの部品 | 色・角丸・影は `--mg-*` を使う。**色コードを直接書かない** |

各画面は `tokens.css` → `app.css` の順に読み込みます。レジはオフラインでも開くので、Service Worker（`sw.js`）がこの 2 つと `help.css` をキャッシュします。CSS を変えたら `sw.js` の `VERSION` を変えてください。

|---|---|---|
| `--mg-bg` | 画面の背景 | クリーム `#fbf7f0` |
| `--mg-surface` | カード・ダイアログ・入力欄 | 白 |
| `--mg-surface-alt` | カードの中の区画 | `#fdfbf8` |
| `--mg-surface-sub` | 控えめなボタン・バーの溝 | `#f1ebe2` |
| `--mg-surface-done` | 済んだもの（受付の受け渡し済みのカード） | `#f6f2ec` |
| `--mg-text` | 本文 | 墨 `#2b2420` |
| `--mg-text-sub` | 補足の文字 | `#7a6f66`（白地で 4.9:1） |
| `--mg-border` | カード・区切り線 | `#ebe3d8` |
| `--mg-border-field` | 入力欄の枠 | `#7a6f66` |
| `--mg-primary` | 主なボタン・リンク・選択中（キーカラー） | 茶 `#8a5a3b` |

### 色の使い分け

- **茶（キーカラー）**：押すと何かが進むもの。主なボタン、リンク、選択中の項目
- **ピンク（アクセント）**：「数」に関わるもの。レジの枚数のボタン、受付の券種ごとの残りの枚数
- **状態の色**は意味が決まっているので、飾りには使わない。緑＝できた・オンライン、赤＝取消・エラー・消す操作、山吹＝時間がたった・未送信、青＝お知らせ
- 色だけで状態を伝えない。必ず言葉（「取消」「未送信 2 件」）や線（打ち消し線）を一緒に出す
- 文字の色は背景と 4.5:1 以上。白地にピンク・山吹の文字を書くときは `-text` のトークンを使う

## 文字

- フォントは `--mg-font`（DADS の Noto Sans JP）。太さは 400 と 700 だけ
- 字間は 0.02em。ただし、見出しのリンクのように狭い場所に並べるものは 0
- 大きさは `--mg-text-xs`（12px）〜 `--mg-text-5xl`（57px）の段階から選ぶ。**12px より小さくしない**
- 金額・数・時刻は `font-variant-numeric: tabular-nums`（桁がそろう）

## 部品

### ボタン（`.btn`）

| クラス | 見た目 | 使うところ |
|---|---|---|
| `.btn` | 茶の塗り | その場で主な操作（保存・変更する） |
| `.btn.sub` | アウトライン（白地・茶の枠と文字） | ほかの操作（CSV・画面を開く・戻る） |
| `.btn.danger` | 赤の塗り | 元に戻せない操作（リセット・削除・締め出す） |
| `.btn.small` | 高さ 32px | 一覧の中の操作 |
| `.btn.big` | 高さ 56px | ログイン・記録するなど、画面でいちばん大事な操作 |
| `.btn.block` | 横いっぱい | |

- カーソルを当てると色が濃くなり下線が出る。押したときはもう一段濃くする（DADS）
- 使えないときは DADS のグレー（`--mg-disabled-bg`）
- レジの支払方法・味のボタンは、店の中で素早く押すための専用の部品（大きく、色で見分ける）

### 入力欄（`.field`）

DADS の入力欄に合わせ、枠は `--mg-border-field`、角丸 8px、カーソルで枠が黒くなります。エラーのときは `aria-invalid="true"` を付けると枠が赤になります。ログイン画面の入力欄も同じ形です。

### タグ（`.tag`）

状態を短い言葉で示します。`.tag.accent`・`.tag.success`・`.tag.warning`・`.tag.error`。

### お知らせの帯

レジの通信状態（オンライン／オフライン／未送信）・送れなかった会計・新しい版のお知らせは、DADS のノティフィケーションバナーと同じく「色の地＋同じ系統の枠＋濃い文字」で示します（`-bg`・`-border`・`-text` のトークン）。

### ダイアログ

ヘルプは DADS のモーダルダイアログに合わせ、墨の枠・角丸 8px・影 `--elevation-3`。「閉じる」はアウトラインのボタンです。

## 新しく画面や部品を作るとき

1. まず `app.css` の部品（`.card`・`.btn`・`.field`・`.tag`）で作れないか考える
2. 画面だけの部品は HTML の `<style>` に書き、色・角丸・影・文字の大きさは `--mg-*` を使う
3. 新しい色が必要なときは、`app.css` の 1.（プリミティブ）に足してから 2.（役割）で名前を付ける。画面に色コードを直接書かない
4. キーボードで操作できること（フォーカスの表示を消さない。`outline: none` を書かない）
5. スマホ（幅 390px）で横にはみ出さないこと
