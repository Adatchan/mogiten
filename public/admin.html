はじめに

会計の基本の流れは？
  1. 商品（団子、焼きマシュマロ）ごとに、お客さんが買う本数を入れる（セットは自動で一番安く組まれます）
  2. 「お会計」で合計金額を確認して、お客さんに伝える
  3. 支払方法（現金、PayPay、d払い）のボタンを押す
  4. 現金ならお預かり金額を入れる
  5. 確認画面で内容を見て「はい（記録する）」を押す

記録すると画面下に「記録しました」と出て、お会計は空に戻ります。現金のときは、その表示にもおつりが出ます。電波がなくても記録できます（あとで自動で送信されます）。

ログインのしかたは？

自分の名前（担当者名）と、レジ用のパスワードを入れて「ログイン」を押します。パスワードは店の責任者に聞いてください。名前は会計ごとに記録されるので、本人の名前を入れてください。

ログインは3日間有効なので、同じスマホなら翌日もそのまま使えます。パスワードはスマホに保存されません。

担当を交代するときは？

画面のいちばん下の「ログアウト（担当者の交代もここから）」を押し、次の人が自分の名前でログインし直してください。ログアウトしないまま別の人が打つと、前の人の名前で記録されます。

未送信の会計が残っているときと、電波がないときはログアウトできません。電波のある場所で、上の「未送信」が 0 件になってからログアウトしてください。

会計のしかた

本数の入れ方は？

商品ごとに本数を入れます。団子は「1本」「3本」「5本」のボタンを押すと、その本数になります（足し算ではありません）。それ以外の本数は「＋」「−」で増減するか、数字をタップして直接入力します。焼きマシュマロのようにセットのない商品は「＋」「−」で入れます。

セットの組み方は自動です。たとえば団子4本なら「3本セット＋1本」、7本なら「5本セット＋1本×2」と、お客さんに一番有利な組み方で計算します。

味のある商品（管理画面で味を登録した商品）は、数の入れ方が変わります。お客さんの言う味のボタンを、その本数だけタップしてください（「みたらし2本、あんこ1本」なら みたらし を2回、あんこ を1回）。押しすぎたら、そのボタンの右上の「−」で減らします。合計の本数でセットが自動で組まれるので、味の組み合わせは自由です。入れた味はキッチン画面に注文として届きます。

焼きマシュマロは団子と合わせてセットになります。たとえば団子3本＋焼きマシュマロ2本なら、合わせて5本で「5本セット500円」です。容器代は団子の本数だけで計算します。

「あと1本で〜お得」と出たら？

本数を少し足したほうが合計が安くなるときに出る提案です。上の例では、団子4本だと560円ですが、5本にすると510円で50円安くなります。

お客さんに「あと1本足すとお得になりますよ」と声をかけて、希望されたら黄色の「5本にする」ボタンを押してください。そのままでよければ、何もせず会計に進んでかまいません。

容器代はどうなっている？

容器代は、1回の会計の団子の本数から自動で計算して、合計に足しています（焼きマシュマロは対象外です。対象の商品とルールは管理画面で変えられます）。

  • 1〜2本: なし
  • 3本以上: 10円（何本でも容器1個分）

容器を2個以上渡すときや、容器がいらないお客さんなど、変える必要があるときは、容器代の「−」「＋」で10円ずつ直せます。直すと「手動」と表示され、「自動に戻す」で元に戻せます。本数を変えたときも自動に戻ります。

支払方法のボタンを押したあとは？

お客さんの支払方法のボタンを押すと、記録の前に確認の画面が出ます。ボタンを押しただけでは、まだ記録されません。

PayPay、d払いのときは、お客さんの支払いが済んだのを確かめてから、確認画面の「はい（記録する）」を押してください。

現金のとき（お預かりとおつり）は？

現金では、先にお預かり金額を入れます。「ちょうど」や「¥1,000」などのボタンを押すか、下の欄に金額を入力してください。入れるとおつりが表示されます。合計より少ない金額では「次へ」が押せません。

確認画面では何を見ればいい？

いちばん上の色つきの帯が支払方法です（現金は緑、PayPay と d払いは赤）。本数、合計金額、現金ならおつりを確かめて、よければ「はい（記録する）」を押します。

間違いに気づいたら「いいえ」を押すと、入力したお会計はそのままで前の画面に戻ります。現金で、お預かり金額だけを直したいときは「← お預かり金額を入力し直す」を押してください。

間違えたとき、うまくいかないとき

記録した会計を間違えた

「最近の会計」の一覧で、その会計の「取消」を押します。取り消した会計には取り消し線が引かれ、売上と本数から外れます。正しい内容で、もう一度会計し直してください。

取り消しを間違えたときは、同じ行の「戻す」で元に戻せます。取消と戻すは、誰がいつしたかが記録されます。電波がないときも取り消せます（あとで自動で送信されます）。

ここに出るのは最新の5件です。それより前の会計は、下の「すべての会計を見る」から探して取り消してください（こちらは電波が必要です）。

入力の途中でやり直したい

「お会計」の右上の「クリア」を押すと、本数と容器代が空に戻ります。記録前なら、何も残りません。

電波がないとき（オフライン）は？

そのまま会計を続けてください。電波がないと画面の上の帯が赤い「オフライン（端末に保存）」になり、会計と取消はスマホの中に保存されます。保存した件数と金額は「未送信 ○件」に出ます。最近の会計にも「未送信」と付いて表示されます。

電波が戻ると、古い順に自動で送信され、「未送信 0 件」になります。すぐ送りたいときは帯の右の「送信」を押してください。同じ会計が二重に記録されることはありません。

電波がない状態で画面を開き直しても、レジは開けます（一度でも電波のある場所で開いていれば）。ダッシュボードの数字には、送信されてから反映されます。

「送信できなかった操作があります」と出た

サーバーが受け付けなかった会計や取消です（内容の不備など）。消さずにスマホの中に残しているので、タップして内容を確かめ、必要ならその内容で会計し直してから「この端末から消す」を押してください。

「新しい版のレジがあります」と出た

レジのアプリが更新されたときに出ます。会計の合間に「再読み込み」を押してください。未送信の会計は消えません（会計の途中でなければ自動で切り替わります）。

急にログイン画面に戻った

ログインから3日たったか、店の責任者が管理画面からログインを解除した（締め出した）ときです。もう一度、自分の名前とパスワードでログインしてください。パスワードが変わっていることもあるので、通らないときは責任者に確認してください。

パスワードを入れてもログインできない

パスワードを何度か間違えると、しばらく（10分間）ログインできなくなります。同じ Wi-Fi やテザリングを使っているほかの人も巻き込まれることがあります。急ぐときは、店の責任者に管理画面から解除してもらってください。

そのほか

今の売上はどこで見られる？

レジ画面のいちばん上に、売上、目標までの残り、売れた本数が出ています（30秒ごとと、会計を記録するたびに更新）。くわしい内訳は、上の「ダッシュボード ↗」で見られます。ダッシュボードはログインなしで誰でも見られるので、スタッフで共有するのに使ってください。

売上の明細や操作の記録は？

「売上明細」の「CSVをダウンロード」で、会計ごとの明細（担当者名つき）を Excel で開けるファイルとして保存できます。取り消した会計は含まれません。「操作の記録」を開くと、取消やログインなどを誰がいつしたかを確認できます。

商品・価格、目標金額、パスワードを変えたい

商品や価格の変更、目標金額の変更、レジのパスワードの変更、ログインの締め出しは、「管理画面を開く」から行います。管理画面にはマスターパスワードが必要なので、店の責任者に頼んでください。
